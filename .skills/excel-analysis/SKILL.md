# Excel 数据分析 Skill

描述：面向 Excel/CSV 表格的中文数据分析技能，适合做指标对比、异常发现、趋势总结和运营建议。

标签：Excel, 数据分析, 异常检测, 运营建议

## 使用方式

当用户提供表格数据和分析目标时，请按以下步骤执行：

1. 先识别字段含义、数据行数和关键指标。
2. 如包含数值列，计算均值、最大值、最小值，并识别明显偏高/偏低项。
3. 如包含团队、人员、日期等维度，做分组对比。
4. 输出必须使用中文 Markdown，包含：
   - 核心结论
   - 数据概览
   - 异常或亮点
   - 可执行建议
5. 不要编造输入数据中不存在的字段或数值。
